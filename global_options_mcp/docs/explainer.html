Global Options MCP

This server connects Claude to your Zerodha account, to global market data and to option maths. Use it to research long-dated option positions on Indian markets. It is a research tool. It does not give financial advice.

Architecture

How the parts connect

Option maths and order guards run on your computer. Only data requests and approved orders leave it.

Workflow

From global view to a position

  1. macro_regime_score · Score the global backdrop. The tool checks trends in Nifty, S&P 500 and copper, plus VIX, the dollar, USD/INR, Brent and the US 10-year yield.
  2. global_market_snapshot · See each region and asset class: 1-day to 1-year change, distance from the 200-day average, volatility.
  3. kite_option_expiries · List the long expiries that NFO has today. Use min_days=180.
  4. kite_option_chain · Get the live chain: bid, ask, spread, open interest, implied volatility and Greeks.
  5. long_option_ideas · Rank strikes for your view. The tool removes illiquid legs and uses the ask price.
  6. strategy_payoff · Check the maximum loss and the breakeven of the final structure.
  7. kite_place_option_order · Preview the order. Send it only after you approve it.
Order safety

Five gates before an order goes to Zerodha

Gate 1

Preview by default

If LIVE_ORDERS is not true, the tool sends nothing.

Gate 2

Human confirm

Live orders also need confirm=true. Claude must ask you.

Gate 3

Limit + NRML only

No market orders. Far expiries have wide spreads.

Gate 4

Size caps

MAX_LOTS_PER_ORDER and MAX_ORDER_PREMIUM.

Gate 5

No naked selling

SELL can only close a long that you hold.

Set up

Run it on your computer

python -m venv .venv-mcp
.venv-mcp/bin/pip install -r global_options_mcp/requirements.txt
cp global_options_mcp/.env.example .env      # add KITE_API_KEY, KITE_API_SECRET
.venv-mcp/bin/python -m global_options_mcp.kite_login --write-env   # every morning
claude mcp add global-options -- $PWD/.venv-mcp/bin/python -m global_options_mcp.server

Kite access tokens expire every day. Live quotes need a Kite Connect plan with market data. Without Kite keys, the global-data and maths tools still work.
